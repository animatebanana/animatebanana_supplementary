--------------------------------------------------------------------------------
Frame Image : frame_06.png
Event Delay : 3.5s
Narration   : RawNeRF trains the neural radiance field directly in linear high dynamic range space, learning to denoise the scene jointly.
--------------------------------------------------------------------------------
Frame Image : frame_07.png
Event Delay : 4.0s
Narration   : This allows the pipeline to render full high dynamic range views while simultaneously enabling viewpoint and focus changes.
--------------------------------------------------------------------------------
