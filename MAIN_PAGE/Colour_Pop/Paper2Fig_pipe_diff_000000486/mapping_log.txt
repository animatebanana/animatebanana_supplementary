--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
Frame Image : frame_05.png

--------------------------------------------------------------------------------
Frame Image : frame_06.png
Event Delay : 3.5s
Narration   : The predicted metric mesh is then projected onto the image plane via depth rendering.
--------------------------------------------------------------------------------
Frame Image : frame_07.png
Event Delay : 4.0s
Narration   : This produces a dense rendered depth map of the target object.
--------------------------------------------------------------------------------
Frame Image : frame_08.png
Event Delay : 4.5s
Narration   : In parallel, the Normalized Object Coordinate Space branch processes the image patch.
--------------------------------------------------------------------------------
Frame Image : frame_09.png
Event Delay : 5.0s
Narration   : It predicts a canonical coordinate map defined directly in the object reference frame.
--------------------------------------------------------------------------------
Frame Image : frame_10.png
Event Delay : 5.5s
Narration   : A similarity transformation aligns the rendered depth map with the predicted normalized coordinate map.
--------------------------------------------------------------------------------
Frame Image : frame_11.png
Event Delay : 6.0s
