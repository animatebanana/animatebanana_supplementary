Representation Intervention

A meaningful edit at the plan level propagates downstream. Example instruction, applied to the Transformer Attention Block's presentation plan:

"Present the three prediction heads together."

Before

1. Input embedding
2. Branch A
3. Branch B
4. Branch C
5. Fusion

After (diffed)

1. Input embedding
2. {Branch A, Branch B, Branch C} — together
3. Branch B
4. Branch C
5. Fusion

Result: a single simultaneous-reveal step with narration describing all three branches together, rather than three separate steps. All variants are precomputed — this page never calls the model.
